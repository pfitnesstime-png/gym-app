# Gym App Sample Data Seeder

This repository contains a simple gym app with Firebase-backed pages:
- `index.html` — member register/login with forgot password support
- `trainer-login.html` — trainer login page
- `trainer.html` — trainer panel for workout assignment and progress monitoring
- `app.html` — member dashboard with membership status, workouts, diet, progress photos and BMI tracker
- `admin.html` — admin panel with members, plans, payments, bookings, offer banners and reports
- `admin-login.html` — admin login

## What I added
- `seed-data.html` — a simple demo data seeder page
- sample users, plans, workouts, attendance, and payments data

## Use Instructions
1. Open `seed-data.html` in your browser.
2. Click **Seed Demo Data**.
3. After success, open `index.html` or `admin.html`.

## What data is seeded
- 4 sample users with plan, attendance, diet, and trainer notes
- 4 plan options
- workout assignments for members
- attendance records in `ptSessions` and `attendance`
- payment records in `payments`
